# Showcase: Encrypted Health Risk Scoring

A hospital wants a 10-year cardiovascular-risk score for each patient. The model runs on a server
the hospital does **not** trust with patient data. With CipherCompute the server computes

```
risk = sigmoid(w · standardised_vitals + b)
```

directly on CKKS ciphertexts. The hospital encrypts locally, the server never decrypts anything,
and only the hospital can read the scores.

> All patient data here is **synthetic**, generated by `generate_patients.py`. No real person's
> data is used anywhere in this repository.

## Run it (under 10 minutes, no Docker)

From the repository root, with Python 3.12 (64-bit):

```bash
uv venv .venv --python 3.12
uv pip install --python .venv -e packages/core -e packages/client -e services/api -e services/worker "moto[server]" fakeredis
```

Terminal 1 — the whole backend (API, worker, SQLite, Redis and S3 stand-ins):

```bash
.venv/bin/python scripts/devstack.py          # Windows: .venv\Scripts\python scripts\devstack.py
```

Terminal 2 — the walkthrough:

```bash
cd showcase/health-risk
../../.venv/bin/python walkthrough.py
```

It finishes in about 10 seconds on a laptop. Against a real deployment:
`python walkthrough.py --server https://api.example.com`.

## What happens, step by step

| Step | Where | What |
|---|---|---|
| 1 | hospital | Asks the parameter advisor what the computation needs: logistic regression with a degree-3 sigmoid costs **3 multiplicative levels**, so it gets N=8192, primes `[45,30,30,30,30,45]`, 128-bit (the *deep* profile). Generates the key ring locally. |
| 2 | hospital → server | Uploads the **public** bundle only (public, relinearization and Galois keys, ~65 MB). The server would reject a bundle containing a secret key. |
| 3 | hospital | Standardises each vital sign with the model's training means/stds and encrypts **one ciphertext per feature column** (up to 4,096 patients per ciphertext). |
| 4 | server | Evaluates `w·x + b` (one plaintext-ciphertext product per column) and the polynomial sigmoid on the ciphertexts. The depth report shows 3 of 4 levels used. |
| 5 | hospital | Downloads and decrypts the scores, compares with the plaintext model. |
| 6 | anyone | Shows what the server actually stored: a small metadata header and ciphertext bytes. |
| 7 | hospital | Checks the job manifest and recomputes the result in plaintext — a guard against a server that returns wrong answers. |

## Results (from a real run)

```
Max |encrypted - plaintext polynomial model| = 2.35e-04   (CKKS approximation error)
Max |encrypted - exact sigmoid|            = 0.098      (degree-3 sigmoid approximation)
AUC: encrypted 0.861 vs plaintext 0.861
```

Two different approximations are at work, and the numbers separate them:

* **CKKS noise** changes each score by at most 2.4×10⁻⁴: the homomorphic computation is faithful.
* **The polynomial sigmoid** changes scores by up to 0.098 compared with the exact logistic
  function — but it is monotonic on the model's logit range, so the *ranking* of patients, and
  therefore the AUC, is unchanged. A degree-5 sigmoid halves the gap (0.047) at the cost of a
  fourth level (`--degree 5` needs N=8192 deep or N=16384).

## What the server can and cannot learn

| The server sees | The server never sees |
|---|---|
| Ciphertexts and their size, the number of patients per ciphertext (unless padded with `pad_to`) | Any vital sign of any patient |
| The model weights and intercept (plaintext arguments, by design) | Any risk score |
| Who submitted what, when (audit log) | The secret key |

If the model itself is confidential, encrypt the weights too: it costs one extra level.

## Files

| File | Purpose |
|---|---|
| `generate_patients.py` | Seeded synthetic cohort (`data/patients.csv`, 2,000 patients) |
| `train_model.py` | Logistic regression by Newton's method; checks logits stay in [-8, 8]; writes `model/model.json` |
| `model/model.json` | Trained weights, standardisation, and evaluation (AUC 0.861 on the held-out 30%) |
| `walkthrough.py` | The scripted demo above |
| `keys/`, `output/` | Created at run time, git-ignored; `keys/` holds the hospital's secret key |
